# 当前开发政策

> 维护者决定：2026-11-19。本文记录本轮仓库整肃的执行规则。

## 1. 当前工作方式

本轮整肃已获维护者授权，由代理实施，维护者审计并决定合并。实现围绕明确的问题、实际行为和可复现结果推进。版本名、工程冻结范围、测试入口和支持额度由维护者按当前工作调整；这些工程约定本身不作为数学结论。

每次交付记录修改范围、实际执行的检查及结果。相关对象或接口只有一处当前定义，其余入口引用该定义。用到尚待研究的性质时，把依赖写在该性质的使用位置，并继续推进与它无关的部分。

## 2. SHA 校验关闭

维护者决定停用整个仓库的 SHA 一致性验证系统，范围包括：

- 源码、交付清单、构建工件和历史证据 pin 的 SHA 比较；
- CI、打包、工作流和复现工具中的 SHA 一致性门禁；
- 协议内 Profile、对象、引用、快照、输入、输出、事件和日志摘要的复算与相等判定；
- `question_id`、`execution`、`environment`、`binding` 等业务路径中以摘要相等或不等为条件的拒绝；
- B/Q 研究投影的 scope、network、weakening-edge 摘要绑定。

摘要字段保留为记录数据；现有生成函数可继续生成记录值。接受、拒绝、状态迁移和测试通过以当前仍执行的内容检查为准，摘要值与复算结果的相等性按本轮决定退出判定。

**实施状态：** 当前登记的摘要规则和执行入口已同步停用政策。摘要字段继续记录；本次实际测试结果随变更交付。

旧文档中的摘要公式、owner SV、固定清单和已发布值保留供追踪。它们的本轮状态为**停用**，不能记作本轮已经验证了摘要绑定、来源真实性或记录完整性。代码中的签名、实际数据、预算和状态检查分别按其当前实现描述；停用 SHA 比较不构成这些机制的验收结果。

## 2A. 工程上限的本轮处置

维护者进一步授权移除精确工具版本门禁，以及 codec 的 1MiB 字节、48层、10000项上限、由其派生的 JSON/行上限、general_job 的16任务上限和按全作业任务数缩小 literal 的阈值。B/Q 研究中的 placement 总体12、校准总体50、样本500、候选10、名称80字符、分数6位、tick 10^9及输入1MiB工程上限也已获授权移除；校准最小样本仍依据原不等式求解。环境版本继续记录；实际编码类型、数值表示、签名、业务状态、预算、授权和数学前提分别按对应实现处理。运行入口的实际变更和检查结果在本次交付记录，不能从政策文字推定所有改造均已完成。

本轮补充决定同时取消事件总数256、响应证明的codec派生额度、FM输入4096字节/256项与工件及声明输出16384字节、测试HTTP帧64KiB与JSON24层/10000项等机械上限。请求认证、签名、精确帧长度、输入类型和每项任务声明的执行预算继续执行。`--production` 作为兼容参数运行同一组已实现规则，工具输出当前检查范围。

## 3. 贡献与审计

当前接收组织内协作，组织外 Pull Request 暂停接收。来源与许可记录继续随贡献保存。代理提交使用维护者指定身份，代理不填写 `Signed-off-by`；签署和合并由维护者处理。

本轮由维护者审计。代理提供可定位的改动、测试和残留事项，维护者据此判断处理结果。历史审计、失败报告和发布快照保留原文与原日期；它们说明当时运行，新的结果另记。

## 4. 已实现行为的呈现

当前入口按“已实现行为、实际适用条件、证据位置、下一步”组织。实现选择写成选择；测试结果绑定实际输入和环境；数学命题写出其前提。把已有明确机制说清，避免用“整体闭合”“严格更优”或没有比较对象的“更安全”等词替代具体结果。

同一对象统一名称；不同层的结果保留层级，例如实验 `ACCEPT`、audit-only `CONCORDANT` 与协议终态分别说明。版本与支持额度的调整记录它影响的输入和行为，不再以全仓同步或额外审批作为默认前提。

## 6. 与旧流程的关系

本轮较新的维护者决定优先于旧 ENV-1、PARALLEL-1、审计程序、Profile 规范和 ADR 中与本文相冲突的工程门禁、SHA 判定与代理审计要求。协议的实际状态机、预算、输入输出语义及数学前提逐项按实现和研究记录核对。本政策不把旧证明或旧测试结果改写为新结果。
