# B/Q 研究第二片：任务级校准与敏感性

日期：2026-10-26；标识 `BQ-W4-S2`。接续[第一片边界](bq-boundaries-slice1.md)。
**本片完成固定样本 Q 校准方法、严格合成输入合约及五组精确敏感性分析；未收集部署校准样本，未估得现实 B/Q，不启用 REEXEC_BOUNDED。**

## 1. 校准范围

| 对象 | 本片处理 | 必须额外提供的依据 |
|---|---|---|
| Q/δQ | 对独立真值已知的正确候选，统计任务级 M<Q 失败数；精确固定样本检验 | 校准任务随机取自目标任务分布，指标 iid，真值来源独立，Profile/总体/资源/期限匹配 |
| B | 只作“未计入多少可能错误支持单位”的外生敏感性输入 | 开放总体全部允许策略、串谋/共因能力集合界及与排列的关系；有限无错样本不能证明未使用能力不存在 |
| 漏簇/共同故障 | 构造潜在能力增加、正确支持减少和任务级共同尾部 | 漏簇规模、支持损失或故障质量的现实上界；本片不估这些量 |
| 域漂移 | 未匹配 scope 直接拒绝；另演示给定 TV 界的保守传播 | 目标分布差异的外生上界与有效期；字段相同不证明同分布 |
| 活性预算 | 沿用原精确有限总体 DP，比较旧预算与未来新参数 | 全部 Bridge/抽样前提仍有效，Nrequired≤冻结 Nmax |

B 的安全前提与 Q 的活性校准分开，二者不能用同一批多数结果循环定义真值。这里的 iid 是**任务级指标**条件；一个任务的 G 个票不是 G 个校准任务。仅有限交换性不足以支持本片二项式 iid 检验。更多一般的依赖、分层或 anytime-valid 校准不是已完成能力。

## 2. 冻结输入与真值契约

[合成样例](../../tests/bq_calibration/fixtures/synthetic-v1.json)是 80 条人工正确支持数均为 8 的记录，明确 `data_kind=synthetic`。这些数值为人工构造，不是实际双机测量，也不声称是从真实分布随机抽到。研究工具当前仅接受这一类显式合成输入；真实观察数据适配/取证尚未实现。

研究输入 `aclt.research.bq-calibration@1` 不是正式协议 schema，不签发 Receipt 或 Profile。封闭字段与校验见[实现](../../tools/bq_boundaries/calibration.py)：

- **scope/target_scope**：任务族、Profile、资源、总体、真值政策、deadline 和抽样政策摘要。任何字段变化不自动外推；聚类定义变化也改变总体，需要重做绑定。
- **truth**：显式合成独立 oracle 与 provenance digest；拒绝以 worker 多数/相同解释器输出自证正确。现实中仍需独立谓词、证书或经审查的任务真值，并记录来源误差。
- **plan**：独立任务单位声明、固定样本数、事前有限 Q 家族、α 与 δQ。不得反复加样本直到通过，或观察后挑数据/候选。声明不等于真实预登记证据。
- **rows**：task ID、依赖 block ID、正确候选标签及正确支持数。已知重复 task/block 拒绝；block ID 不同不能证明不存在未知共同故障。无真值拒绝。已知正确任务在固定期限内无支持时，可显式记 null 并按 M=0 消费，不可丢掉该任务 slot。

scope、digest、iid_asserted 都只是研究输入声明。哈希或结构检查不证明真值、随机来源或独立性。即使统计检验通过，输出仍固定 `automatic_deployment_eligibility=false`、`empirical_calibration_established=false` 和 `B_estimated=false`。

## 3. 精确固定样本校准

对事前固定 Q，令任务级变量 Yᵢ(Q)=1{Mᵢ<Q}。在 n 个 iid 任务、固定 n 下，k=ΣYᵢ，目标 pQ=P(M<Q)≤δQ。计算：

\[
T_{\delta_Q}(n,k)=\sum_{j=0}^{k}{n\choose j}\delta_Q^j(1-\delta_Q)^{n-j}.
\]

若事前固定 K 个候选 Q，则本片保守采用 `T≤α/K` 才标为 conditional_pass，并从通过项中取最大 Q。二项式下尾关于 p 单调，所以每个不满足目标的 Q 误通过概率≤α/K；对固定家族作 union bound，挑选后的误颁证事件概率≤α。不同 Q 的检验不要求互相独立；也不宣称 Bonferroni 是利用嵌套结构的最优方法。

这相当于检验目标 δQ 的单侧精确阈值，不求近似置信端点，不用浮点、正态近似或有限样本均值充当覆盖率。方法背景见 [NIST 官方单/双侧 exact binomial 说明](https://itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbino.htm)；NIST 不证明本项目数据 iid、Bridge 或部署安全。

### 三类误差不能混在一起

- **α**：有限校准过程误给出不满足目标的 Q 的频率上界。
- **δQ**：在有效校准与同适用域前提下，未来正确任务的支持数低于 Q 的质量上界。
- **δL**：给定 M≥Q 时，有限总体抽样未在预算内达到停止条件的上界。

正确表述是：在概率至少 1−α 的校准好事件上，通过并选定的 Q 满足目标；在其余前提成立时，未来任务活性失败风险≤δQ+δL。跨校准与未来任务，可保守界定**“工具建议发布且未来活性失败”这一联合事件**的概率≤α+δQ+δL。它不是“已经通过这一批数据之后，Q 有 95% 后验概率正确”，也不是条件于通过/发布后仍自动具有同一个无条件界。没有发布时不把拒绝算成任务成功。

本校准 α 与运行中 εF 分属不同预算；这里没有把 α 自动加入协议 Type-I 界，也没有证明 B/抽样来源无误。重复发新版本、跨多个任务域或反复看样本需另行分配误差预算；本片不支持可选停止。

## 4. 合成校准结果

固定 δQ=α=1/20，所有相关数为人工样例而非测量：

| 观察/方案 | 条件检验结果 | 严格解释 |
|---|---|---|
| 单个事前固定 Q=8，58 个任务、零失败 | 不通过 | 样本不足以给出本片阈值证书，不证明 pQ>δQ |
| 同上，59 个任务、零失败 | 通过 | (19/20)^59≤1/20；58 不满足，故为该规则下精确最小值 |
| 60 个零失败，从 Q=4/6/8 的固定家族中挑选 | Bonferroni 方案下均不通过 | 不能直接沿用单个 Q 的阈值 |
| 80 个零失败，同一家族 | 通过并选择 Q=8 | (19/20)^80≤(1/20)/3；仅为条件研究结果 |
| 80 个任务中 4 个 M=0（或固定期限无响应） | 无 Q 获证 | 缺失计入失败，不把它们删掉后重算 |
| 60 次日志实际只有 6 个已知共同故障块 | 输入拒绝按 60 个 iid 任务校准 | 仅 6 个独立块最小值的比较也不通过；块级界不能直接改称任务级界 |

共同 block 的最小值作为新单位，还需块与块 iid 以及明确的目标块采样分布。去重或取最小值本身不能恢复这些前提。本片只将六块情形作为比较，不颁发任务级 Q。

## 5. 五组敏感性

全部沿用第一片人工底座 G=10、B=3、Q=8、εF=1/5、旧预算 6 draws。以下量是**外部指定的压力参数**，不是从合成/真实票数反推出的估计。

| 轴 | 结果 | 不可误解为 |
|---|---|---|
| 漏计错误支持能力 u=0/1/2/3/5（固定 G 的额外能力单位） | 旧参数下三票 cap 的错误接受率为 1/12、4/21、43/126、11/21、8/9 | “漏一个簇必等于 u=1”；真实簇可能影响多个单位及总体定义 |
| 正确支持减少 L=0/1/2/3 | 旧六步预算活性分别为 1、53/60、2/3、53/126 | 旧 Q 仍适用，或可以事后改预算 |
| 共同任务故障质量 ρ=0/1/20/1/5，正常 M=8、故障 M=0 | 六步活性与 M≥8 覆盖率均为 1、19/20、4/5 | 现实共同故障率已测得；主机独立排除了软件尾部 |
| 外生总变差界 η=0/1/50/1/10 | 若目标 M 分布与校准分布 TV≤η，则尾部保守界为 min(1,δQ+η) | 本工具估到了 η，或字段相同代表 η=0 |
| 未来新政策网格 B′=3+u、Q′=8−L，共 20 点 | B′≥Q′ 时无合法间隔；其余点用原 DP 重算最小预算。例 B′=3、Q′=7 需 7 draws，已超过旧 cap=6 | 用新参数修复旧 Receipt 或仅凭 B′<Q′ 宣称可部署 |

总变差传播用任意事件概率差≤η 的定义。它要求同一明确总体/测量事件下的外生分布距离界，不覆盖任意改变执行语义或抽样机制。本片保守联合界示例为 min(1,α+δQ+δL+η)，各项依赖前提须同时成立。若没有 η 的依据，就没有自动的定量外推保证。

**正间隔与预算均符合仍不是启用条件。** B′ 的能力集合依据、随机性、Snapshot、真值/时序与准入 assurance 仍未建立；Grid 的 fits_six_draw_budget 只是算法成本比较。
