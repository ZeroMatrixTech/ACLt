# B/Q 研究第一片：反例与模型适用边界

日期：2026-10-26。工程标识 `BQ-W4-S1`，属于原定第四项“B/Q 的反例与校准研究”。
**结论：本片给出八个精确小总体反例/见证，说明本轮观测不能替代 B 的外生能力集合约束或 Q 的同适用域覆盖率。未建立任何实际部署的 B/Q。**

## 1. 研究问题与模型

权威定义以[有限总体数学模型](verification-round-mathematical-model.md)和[结果验证](../03-protocol/result-validation.md) §4–7 为准。保留现有算法 `finite-population-boundary-lr-v1`、递推状态机和独立闭式/DP oracle 原字节，不修改条件安全证明。

- 候选 c **无效**时，A⁻(c) 是所有在允许策略下可能支持它的相关集群集合；C=|A⁻(c)|。B 是排列前冻结、含串谋/共因/移动腐化可能支持者的外生上界，不是已投票数。能力集合及其与 draw order 的关系都需依据。
- 候选 c **有效**时，M(c) 是在冻结语义、资源与缺失处理下的正确支持数。Q 是同适用域的任务级支持下界，覆盖率为 1−δQ；不是平均票数、单节点成功率或历史最好成绩。
- G 是冻结集群级抽样总体，不能从身份/进程/机器数直接得到。许可成员登记也不自动排除共同软件故障。
- 固定 A⁻、独立均匀不放回抽样、C≤B 及其余 Bridge 条件成立，才适用 εF 条件界。Q 主要承担活性下界；Q 校准失败不等于 B 安全界本身失败，但停止概率/预算声明失效。

本片固定 G=10、B=3、Q=8、εF=1/5，仅为可全枚举的反例参数，不是生产推荐。对每个固定能力集，均匀枚举所有 C 个支持能力位置组合，每个权重为 1/choose(G,C)，用精确 Fraction 递推，保留首次接受。C>B 的路径故意违反假设；kernel 的 ACCEPT 不是获准输出 TRUSTED，也不是运行时可以自行检测 B 错误的信号。

实现入口：[model.py](../../tools/bq_boundaries/model.py)、[回归](../../tests/bq_boundaries/test_boundaries.py)、[重跑脚本](../../scripts/check-bq-boundaries.py)。只用标准库，无 Monte Carlo、浮点阈值、真实网络或攻击部署。

## 2. 八个边界见证

### BQ1-CAPACITY：串谋可支持集合大于实际票数

每个有能力单位在被抽中后支持，累计投满三票即弃权。三票预算保持不变，但能力集随 C 扩大：

| 实际 C | 实际支持票数上限 | 错误接受概率 | 是否超过 εF=1/5 |
|---:|---:|---:|---|
| 3 | 3 | 1/12 | 否，有效模型对照 |
| 4 | 3 | 4/21 | 否，违反前提未必马上数值越界 |
| 5 | 3 | 43/126 | 是 |
| 6 | 3 | 11/21 | 是 |
| 8 | 3 | 8/9 | 是 |
| 10 | 3 | 1 | 是 |

这些数值复现既有数学模型的反例，属于复现性证据；本片不主张首次发现。本片把它与其他部署失效方式放在同一可重跑证据中。票数上限、低支付、质押或损失 cap 均不能单独证明能力集合界；它们可限制损失但不修复统计条件。

### BQ1-SYBIL：同一完整 transcript 无法识别未使用的能力

两个模型世界的可见字段完全相同：10 个申报单位、同一 draw order、七个不支持后三个支持、同一个声明 B=3。

- 世界甲：只有最后三个单位有支持错误候选的能力，C=3。
- 世界乙：全部十个单位有该能力，但前七个选择弃权，C=10；可对应一个控制者的多个身份或协同单位。

相同 transcript 在两个世界均可行，能力集合不同。它证明的是：**仅在本片定义的可见字段和无限制潜在策略模型内，无法由这段观察唯一识别 C。** 不是关于加入可信设备证据、受限攻击模型或任务专用证明后仍然不可能的一般定理，也不是对实际节点的指控。

### BQ1-COMMON-MODE：非恶意共因也进入错误支持能力

若十个名义单位运行同一有触发条件的错误实现，对该无效候选均可能支持，则 C=10；三票上限下错误接受率可为 1。恶意控制比例即使为零，也不推出 B=0。相同实现本身不证明一定有此缺陷，本见证只是未排除世界。

若保守地将所有单位合并为一个相关簇，则该错误簇可能支持，G=1、所需 B=1，不满足 B<G，更不满足 B<Q≤G。**聚类不会凭空创造安全余量。** 两台物理机并不排除共同解释器/编译器/规则缺陷。

### BQ1-RESPONSE-FILTER：只保留响应者会改变抽样条件

实际 C=3，原冻结十个 slot 均匀抽样并消费其二元观测，错误接受率为 1/12。失效实现却把所有 0 视为不回包并丢弃，按三个支持回包重新编号 draw；第二个支持时 kernel 已接受，错误接受率为 1。

这不是提出“所有缺失必须永远记 0”的协议新规则；只是展示当前二元语义下，**过滤缺失/不支持再补抽，不能继续声称原均匀有限总体模型。** timeout、缺失、拒绝和非 OK 的编码、消费 slot 和期限必须事前冻结；若改抽样设计，应有新的充分条件与证明。

### BQ1-ORDER：固定集合不够，还要与排列独立

C=3≤B 不变，但排序方知道能力成员并将三个支持者放在前面，错误接受率为 1。对照均匀随机仍为 1/12。真实支持数没有超限，坏的是条件均值/随机排列前提；能被 grind、预知或按响应选择的排列不是模型中的均匀排列。

### BQ1-Q-MEAN：平均支持数不等于覆盖率下界

构造任务级共同故障分布：以 4/5 概率十个单位都支持正确候选，以 1/5 概率全部不支持。E[M]=8，但 P(M≥8)=4/5，不能声称 Q=8 的覆盖率为 19/20。

这里的 1/5 是人工指定的共同故障质量，不是测得的现实故障率。平均完成率不能给出 δQ，两个宿主“都成功过”更不能排除共同尾部。

### BQ1-Q-SHIFT：同一历史不能约束未建模的新适用域

两个世界共享三份有独立真值标签的训练 fixture，历史均为十份正确支持。目标任务正确且尚未观察：一个世界有 8 个正确支持，另一个存在未见触发条件/共同不可用而为 0。两者历史可见数据相同。

没有额外同分布/交换性、任务域覆盖、固定 Profile/资源/期限与漂移限制，历史不决定新任务 Q。本片不拟合置信区间，不宣称有限样本校准绝不可能；有明确适用域和统计假设后如何校准，留第二片。

### BQ1-Q-BUDGET：Q 低估失败会直接破坏活性预算

用声明 Q=8 与 δL=1/20，原精确 DP 的最小预算为 6 draws，在 M=8 时接受概率为 1。实际正确支持只有 M=7 时，同一预算接受概率降至 53/60，低于所承诺 19/20。这是**活性**反例，不是错误候选接受率。

即使 Q 事先有合法覆盖率，结论仍受 δQ+δL 以及 Nrequired≤Nmax 限制；不能观察到慢任务后临时扩预算来补原承诺。

## 3. 防止误归因的有效模型对照

- 55 组小总体有效均匀 null 参数下，枚举错误接受概率均≤1/5。
- 固定 C≤B 时，让有能力单位根据历史自适应支持/弃权，旧最坏策略 DP 仍在 εF 内；不是“所有自适应策略都不允许”。禁止的是集合外能力转移和不满足条件界的抽样。
- 6 行能力/票数反例，用新逐步状态机枚举对拍未修改的下降阶乘闭式 oracle。
- M=0～10 的 11 条完整吸收曲线，用新组合枚举对拍未修改的闭式有限总体 DP。

这两条计算路径共享 Python Fraction 与既有算法语义，不能冒称两语言或完全独立供应链实现；枚举本身不是开放世界安全证明。

## 4. 可观察项与待补的外生证据

| 量/事实 | 本地或双机可观察部分 | 观测本身不能给出 | 失效时边界 |
|---|---|---|---|
| 身份/物理部署 | 公钥、声明、目录、已记录主机与连接 | 控制独立、无共同实现错误、相关簇完整性 | 不由 ID/主机数量推 B/G |
| C≤B | 已签支持/不支持的结果与本轮日志 | 未使用能力、触发式串谋、开放未知控制者的全集上界 | B 无依据则 audit-only/禁用 bounded |
| 随机抽样 | 冻结名单、承诺、draw order、slot/timeout 日志 | 隐藏预知/grinding/旁路已被排除 | 无来源证据不能引用 εF 界 |
| Q/δQ | 有真值标签的任务级支持数与环境记录 | 未测任务域、漂移或共同故障的覆盖率 | 不声明原停止预算保证 |
| 预算/恢复 | 明确尝试、期限与花费 | 正确性或支持能力界 | 只限制消耗，不能替统计条件 |

B 和 Q 的真值标签来源必须分别登记；用当前候选多数给训练任务贴“正确”标签是循环论证。本片没有实现生产 gate 或新降级状态，处置沿用现行 Profile 和 ADR-0005；第三片再整理部署判断清单。
