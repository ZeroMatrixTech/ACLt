# 接纳端回滚与复制保护：2026-10-20 工程记录

这是实现与实测记录，不是独立第三方审计，不改变协议状态或 Gate 结论。

## 改动与适用范围

新增 [v2 实验](../../experiments/aclt-authority-admission/README.md)：外置单一权威账本统一占用资格与接纳结果；接纳端只转发；worker 先持久占用本地资格，再请求并核验绑定任务/请求的权威签名。完整结果可重传，计算不续算、不重试。旧凭据、旧版响应与本地空缓存不能创造新版资格。

本轮保护接纳端快照回滚与复制，假设权威账本、部署配置和密钥可信且不随之回滚。没有证明权威账本自身防回滚、高可用、worker 克隆防重算、物理身份独立性、Sybil 抵抗或生产管理接口安全。正式 Receipt/Lease/RIR/RPR 与 P0-1B 的状态保持不变。

## VM 与独立离线检查

QEMU TCG 软件虚拟化，五台主测试 VM（一个权威账本、两个接纳端副本、两个 worker），另有缺失账本的拒绝启动副本。接纳端从领取前快照回滚，两个副本并发服务，实际网卡断连、响应丢失、worker 重启均保持已声明规则。权威账本在 4 个确定事务检查点和 40 个随机时刻遭整机硬终止；随机种子 20261020，每类事务 20 次。

领取随机样本：12 次重启后已提交、8 次未提交；接纳随机样本：18 次已提交、2 次未提交。随机样本不逐一识别 SQLite 内部写回窗口；确定检查点与随机覆盖分开报告。

共 62 项 VM 场景断言通过。独立核对恢复副本的文件系统日志后，970 项检查通过：56 次持久资格占用，48 次完成的 worker 调用，40 份接纳贡献；同一 claim/unit 未出现第二次资格占用或第二次完成调用。48 个启动意图均对应完成调用，126 份原始权威签名响应核验通过。所有已确认接纳的抽样断电回执在重启后保持一致。原始磁盘摘要不变。

上述数量是场景和证据计数，不是已经实现的协议规则数。资格占用并不等于 worker 收到授权；响应丢失可以消耗资格而不执行。贡献数少于执行数包含注入无效首结果与尚未接纳的完整结果，不通过重算补齐。

## 失败记录与边界

沙箱最初禁止回环网络与 LeakSanitizer；在支持的环境用相同入口重跑通过，未关闭检测器。VM 首次控制端就绪后请求被重置，第二次首次请求超时；驱动修正就绪顺序、增加只读健康探针并放宽 TCG 通信期限。第三次断网验证中，超时请求在恢复后接纳，重传返回 duplicate；原验收只接受 accepted，已改为检查断连期间未接纳、恢复后只有一个贡献和稳定回执。失败现场全部保留。
