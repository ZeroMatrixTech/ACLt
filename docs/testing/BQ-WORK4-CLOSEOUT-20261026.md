# 原定第四项收尾：B/Q 反例、校准与部署边界

日期：2026-10-26（Europe/Budapest）；标识 `BQ-WORK4`。
**三片组成的限定研究工作完成。结论不是“现实 B/Q 已建立”，而是明确哪些前提不能从票数/双机成功记录推得，给出条件校准方法及未获证据时的拒绝/减权边界。**

## 1. 三片交付与结论

| 切片 | 交付 | 本次重跑核对 |
|---|---|---|
| [反例与模型边界](../06-research/bq-boundaries-slice1.md) | 8 个精确人工见证；能力集合/实际票数、Sybil、共因、响应过滤/排序及 Q 尾部/域漂移 | 6 行能力反例闭式对拍、11 条活性曲线 DP 对拍及原有效模型对照 |
| [校准与敏感性](../06-research/bq-calibration-slice2.md) | 固定样本、任务级 iid/独立真值契约；α/δQ/δL 分离；五组敏感性、20 点未来参数网格 | 固定 δQ=α=1/20，零失败单 Q 最小 59，三 Q Bonferroni 方案最小 80；不把 synthetic 结果当现实 Q |
| [证据与失效边界](../06-research/bq-readiness-slice3.md) | 14 项清单、12 个 inventory、8 个创建前选择、19 个生命周期投影 | 正例只是假定来源下的 REVIEW 候选；当前项目正式准入证据不足，未启用能力 |

B 的外生能力集合界不能由有限“没有观测到错误”或最多几票推得。Q 的任务级覆盖率不能用均值、多个回包或同一有限历史替代；本片校准方法需要独立真值、任务 iid、同适用域和固定样本/候选家族。正的 B<Q 间隔还不够，精确 DP 预算、来源和 assurance 都需满足。

上述结论保留原有限总体条件定理，不声称对开放世界作出一般不可能性证明。第一片的两个可见记录等价世界只说明相应观察模型不能唯一识别潜在能力；第二片的人工分布和故障质量不是现实风险估计；第三片的 metadata、digest 和状态标签不是来源认证。

## 2. 统一入口与跨片连续性

新增 `scripts/bq-work4.py` 和显式 `make test-bq-work4`，使用三个既有 CLI 在独立子进程重新计算，逐字段核对各自随仓库保存的原始报告。三个切片、夹具及旧递推/闭式实现原字节保留。

统一锁定 **25 个源码/原始报告/旧工件路径**，不是 25 个独立实现。交叉核对至少包括：

- 同一 G=10、B=3、Q=8、εF=1/5 底座；C=5 且三票 cap 的错误接受率 43/126 与第二片漏计能力 u=2 一致。
- M=7 时原六步预算活性 53/60，在反例与支持损失敏感性之间一致。
- 59/80 的校准样本门槛一致；人工 selected_Q=8 同时保留 empirical_calibration_established=false，不被第三片升为现实来源。
- 第三片引用的第二片报告及五份旧项目材料摘要一致；当前项目 gap inventory 不形成正式 reexec 准入候选。
- 所有生命周期投影保持“不授权 Profile 切换/重参数化/guest 重试/新 TRUSTED”，原终态不会被改写。

run 之后再从另一个进程执行 verify。verify 校验当前源码锁、保存文件清单、原始报告、统一摘要，**在临时目录重新计算本地数学模型**；不访问 SSH/网络、guest、实时注册表或数据库。它不是“只比较旧 PASS”。不产生新部署资格、终态或资金变更。
