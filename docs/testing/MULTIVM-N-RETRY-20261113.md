# 最简验证机 · 无答复的求解计量与补算（2026-11-13）

实跑源码为 `10a115252baa56560660753e216084fbe671310f`。三台同宿主 QEMU 来宾以 TCG、每来宾 1024 MiB 运行固定 `stats-int-v1` 三叶树作业。第二片对应 `SOLVE-1`、输入区间 `[2, 4)`，其额度是 8719 gas。

| 场景 | 求解预算 | 计入 gas | 结果 |
|---|---:|---:|---|
| 正常对照 | 26049 | 26049 | 三片接受 |
| B 保存请求后、求解前退出 | 34768 | 34768 | A 补算一次，C 验证 |
| B 求解并保存答案后、发送前断连 | 34768 | 34768 | A 补算一次，C 验证 |
| 同一丢答复场景 | 34767 | 17438 | 拒绝补算，退出码 1，无归并输出 |

两组补算的归并输出均与单机参照逐字节一致，已接受叶子的实测求解 gas 合计 26049。无答复尝试在协调器账里记为 `NO_REPLY`，`measured_gas` 留空，`charged_gas` 等于该片的额度。成功回复记录实测用量。丢答复场景中，B 盘上的原答复可独立证明执行已完成；协调器在作出决定时只依据它实际收到的信息。补算前检查「已计入费用 + 补算额度 + 所有尚未派发叶子的首算额度」不超过作业预算。

`--retry-solve` 是本实验的显式选项，要求至少三来宾和显式求解预算，每个作业最多补算一次。当前由 A 接手，保留原独立验证方。受固定连接顺序约束，只有当这次求解是原来宾的最后一项计划操作、原验证方也不是 A 时，才会尝试接手。断连的旧连接退出，归并只消费对应叶子经复核的答复。验证、通信、归并仍独立于求解预算。本实验限定于同一次协调器运行，整题资源上限与 trap 组合仍开放。

```sh
python3 -B experiments/aclt-minimal-verifier-baseline/multivm.py run \
  --guests 3 --kernel /path/to/vmlinuz --output /tmp/aclt-retry \
  --solve-budget 34768 --retry-solve --interrupt drop-reply SOLVE-1
```
