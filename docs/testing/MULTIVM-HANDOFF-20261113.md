# 最简验证机 · 协调器交接（2026-11-13）

实跑提交 `2583bf16aed8429ddffe43d37ab2d5d6c509531e`。同一可信宿主以 QEMU TCG、Ubuntu 7.0.0-30-generic 和每来宾 1024 MiB 启动两阶段三来宾实验。固定 `stats-int-v1` 三叶树，整题上限为 9425 gas、144 字节，分片求解预算 26049 gas。

## 交接边界

第一阶段 A 求解第 0 片，B 复核。A 在保存匹配的答复和接受回执后停止，退出码 76。后两片尚未派发，也无归并输出。宿主等待该阶段所有来宾退出，再从磁盘核对冻结计划、A/B 两侧的验证帧、独立复核结果和 8719 gas 的已用预算。发现额外派发帧、回执差异或账目差异则拒绝接手。

宿主把检查过的记录放入新来宾的启动镜像。第二阶段由不同启动标识的 A 实例接手，同样启动新的 B、C 实例。A 重读第 0 片的原答复和接受回执，核对相同的作业、整题题目和已计入预算，再派发第 1、2 片。两阶段的所有旧来宾进程先退出，下一阶段才启动。宿主在实验中承担这一唯一接手条件及状态转交。

## 结果

两阶段通过。三片各保留一次求解，合计 26049 gas；交接时余量为 17330 gas。两阶段分片、验收和归并使用相同作业 ID。最终归并输出与单机参照逐字节一致，SHA-256 为 `1216b67718f016f305a97cc465db4f34fb268c348fde0f1e75befbf49a347d56`。两阶段启停及交接共 21.79 秒。

[证据包](public-evidence/MULTIVM-HANDOFF-public-evidence.tar.gz) SHA-256 为 `afb61234eaa3286b49d546ad5cfa2238715a956a2aadeccff18664d0b9324201`。默认最简验证机回归重放两阶段证据，检验提前派发和少计 gas 时拒绝交接。离线重放的复核成本独立于作业求解预算。
