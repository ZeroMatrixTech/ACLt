# Independent candidate claim codec

Build with `rustc --edition=2021 -D warnings -C overflow-checks=yes -O main.rs -o /tmp/aclt-claim-codec` from this directory, or run `make test-claim-codec` from the repository root. No Cargo dependencies or Python subprocess are used by the executable.

Each stdin line is `kind<TAB>lowercase-cbor-hex`; `view-kind<TAB>json` performs the inverse typed projection first. Output is one JSON result or error per line. Public kinds are uint, int, bool, text, bytes, digest, semver, rational, version-range, text-set, template, claim and chain. The `sha256` mode is a test hook taking hex bytes. No mode authorizes production admission.

The Python and Rust implementations independently parse CBOR, check typed objects, project Schema View, encode CBOR and hash. SHA-256 is stdlib hashlib in Python and a separate implementation in sha256.rs. OpenSSL also checks both frozen object digests. They intentionally share the candidate contract, input vectors and Unicode version; differential agreement alone is not a proof of protocol completeness.

`unicode_data.rs` contains canonical decomposition, combining classes and allowed composition pairs generated by `generate_unicode.py` from CPython's Unicode 16.0.0 database. It contains data, not Python normalization code. Rust implements decomposition, stable canonical ordering, composition and Hangul independently in nfc.rs; Python uses unicodedata.normalize. Python must expose Unicode 16.0.0; mismatched database versions fail closed. Reproduction: run `python3 generate_unicode.py` and compare the resulting bytes. The generator contains no network access.

Data provenance: [Unicode Character Database](https://www.unicode.org/ucd/), as supplied by CPython 3.14.4 `unicodedata` version 16.0.0. Generated data retains the [Unicode license](https://www.unicode.org/license.txt), copied into UNICODE-LICENSE.txt on 2026-10-23. The normalization and hash implementations in this directory were written for this slice and use Apache-2.0; no external implementation source is copied.

See schemas/verification-profile/claim-codec-slice.json and docs/testing/CLAIM-CODEC-20261023.md at the repository root for the candidate wire contract and deliberate limits.
